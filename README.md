# Мебельная фабрика «Профиль» — панель учёта производства

Веб-панель, которая объединяет два журнала (простои и брак) и показывает директору, **где фабрика теряет время и деньги и что с этим делать**.

## Как запустить (30 секунд, ничего устанавливать не нужно)

1. Распакуйте архив.
2. Откройте файл **`panel/index.html`** двойным щелчком (или файл `index.html` в корне — он сам переведёт на панель). Подойдёт любой современный браузер: Chrome, Edge, Firefox, Safari.
3. Панель откроется сразу с данными за 19.05–15.06.2026: интернет не нужен, все библиотеки лежат в папке `panel/lib`.

Если панель опубликована на GitHub Pages — просто откройте ссылку.

## Что есть на панели

| Лист | Что показывает |
|---|---|
| **Сводка** | Потери времени, доступность станков, брак, потери в деньгах; автоматические выводы «что видно по данным» с советом «что делать»; два ключевых графика |
| **Простои** | Тепловая карта «станок × день» (с выбором причины), Парето причин, простои по станкам и причинам, день/ночь по станкам, плановое ТО отдельно |
| **Брак** | Динамика по дням и сменам, брак по операциям, недельная динамика «день / ночь» по каждой операции, типы дефектов |
| **Данные** | Обе исходные таблицы с поиском и сортировкой по клику на заголовок; над таблицей — итоги по видимым строкам, чтобы любую цифру проверить вручную |

## Обязательные функции

- **Загрузка данных по кнопке.** «Загрузить данные» (справа вверху) принимает файлы CSV и XLSX — можно выбрать сразу оба. Панель сама определяет, где простои, а где брак, читает кодировки UTF-8 и Windows-1251, разделители `;` `,` и табуляцию, даты `ГГГГ-ММ-ДД` и `ДД.ММ.ГГГГ`. Строки с ошибками пропускаются и перечисляются в отчёте под шапкой. «Вернуть исходные данные» возвращает встроенные журналы.
- **Скачать PDF на каждом листе.** Кнопка сохраняет именно открытый лист (в светлой теме, с разбивкой на страницы A4 и подписью «лист · фильтры · страница»).
- **Фильтры**, влияющие на все графики и цифры: период (даты или быстрые кнопки «Нед. 1–4»), смена, цех. В журнале брака нет цеха, поэтому фильтр по цеху действует только на простои — это отмечено на панели.

## Допущения (важно)

В исходных журналах нет объёма выпуска и денег. Поэтому:

- **«Выработка» = доступность оборудования**: фонд времени (станки × дни × смены × длительность смены) минус потери и плановое ТО;
- **рубли** считаются по ставкам, которые можно менять в блоке «Допущения для расчёта времени и денег» на Сводке. По умолчанию: смена 8 ч, станко-час простоя 3 000 ₽, бракованная деталь 1 500 ₽. **Это оценка, а не бухгалтерские данные.**

## Как проверить, что цифры не выдуманы

Контрольные цифры исходных данных: 120 записей простоев на 6 960 мин (из них 5 635 мин — внеплановые потери = 93,9 ч), 94 записи брака на 218 шт.

Автоматическая сверка — `tools/verify-panel.js`: скрипт независимо разбирает исходные файлы и сверяет их с панелью по 54 комбинациям фильтров (1 089 проверок: KPI, суммы всех графиков, тепловая карта, лист «Данные»). Запуск: `node tools/verify-panel.js` (нужны Node.js и Microsoft Edge; Windows). Последний прогон: **0 расхождений**.

## Состав архива

```
index.html                 переход на панель
panel/                     сама панель (index.html, css/, js/, lib/, data/)
tools/embed-data.js        встраивает исходные файлы в панель как данные по умолчанию
tools/verify-panel.js      независимая сверка цифр
Файлы для проекта/         исходные журналы (CSV и XLSX)
ОПИСАНИЕ.md                выводы по производству и где они видны на панели
КОММЕНТАРИЙ.md             свободный комментарий: где было сложно, где помог ИИ, где поправил
журнал-правок.md           подробный журнал ошибок ИИ и исправлений
```

## Технологии

Чистые HTML/CSS/JS без сборки. Библиотеки (лежат локально в `panel/lib`): Chart.js 4.4.1 — графики, SheetJS 0.18.5 — чтение XLSX, html2canvas 1.4.1 и jsPDF 2.5.1 — PDF.
