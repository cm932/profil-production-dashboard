# Мебельная фабрика «Профиль» — панель учёта производства

Панель объединяет два журнала (простои и брак) и показывает директору, **где фабрика теряет время и деньги и что с этим делать**. Есть вход по логину и паролю, четыре уровня доступа и админ-панель.

## Как открыть

Распакуйте архив целиком. Пошаговая инструкция с картинками — файл **`Инструкция.html`** в корне архива. Коротко:

| Файл | Для чего |
|---|---|
| **`Запуск сервера Windows.cmd`** | полная версия на Windows: сервер, база SQLite, админ-панель; браузер откроется сам |
| **`Запуск сервера Mac.command`** | то же на Mac (Apple Silicon и Intel); первый раз — правая кнопка → «Открыть» |
| **`Открыть без сервера.html`** | запасной вариант для любой системы: данные внутри зашифрованы, логин и пароль служат ключом; без админ-панели и без сохранения правок |

Node.js лежит в папке `runtime` (для Mac сжат xz, чтобы архив помещался в 100 МБ; при первом запуске распаковывается сам, контрольная сумма проверяется), поэтому ничего устанавливать не нужно. Пока идёт работа с полной версией, окно сервера не закрывайте. Если порт 3000 занят, сервер сам берёт свободный.

Если файл для Mac не запускается: Терминал → `bash ` (с пробелом) → перетащить `Запуск сервера Mac.command` в окно → Enter. Если и так не выходит — «Открыть без сервера.html».

### Учётные записи (демонстрационные)

| Логин | Пароль | Роль | Что видит и может |
|---|---|---|---|
| `admin` | `Admin-2026!` | Администратор | всё; «Админ-панель»: пользователи, журнал действий, служебное; правит любые записи |
| `director` | `Director-2026!` | Директор | все листы, деньги и ставки, загрузка файлов, PDF |
| `chief1`, `chief2` | `Chief1-2026!`, `Chief2-2026!` | Начальник цеха | только свой цех, без денег; добавляет и правит свои записи простоев |
| `otk` | `Otk-2026!` | Оператор ОТК | только брак; добавляет и правит свои записи брака |

Эти же пароли указаны в `Инструкция.html`. Если архив передаётся широкому кругу, пароли лучше сообщить отдельно и убрать из инструкции.

## Что на экране

Каждый лист целиком помещается в окно (ориентир — ноутбук или монитор 1920×1080 с масштабом Windows 125 %, это ≈ 1536×730 точек в браузере). Правило раскладки — **«один экран — одна мысль»**: вместо шести мелких графиков на лист у листа есть вкладки, и каждая вкладка показывает один-два крупных графика. В PDF попадают все вкладки листа, каждая на своей странице.

| Лист | Что показывает |
|---|---|
| **Сводка** | 4 показателя (потери времени, доступность станков, брак, деньги) и 3 главных вывода крупными карточками: цифра, пояснение, мини-график, «что делать». «Подробнее» открывает разбор; кнопка «Все выводы» — полный список за период |
| **Простои** | вкладки «По дням» (тепловая карта «станок × день» с выбором причины), «Причины» (Парето и станки по причинам), «День и ночь» (станки по сменам, итоги, плановое ТО отдельно) |
| **Брак** | вкладки «По дням» (динамика и операции) и «По неделям» (день и ночь по каждой операции в одной шкале, типы дефектов) |
| **Данные** | обе таблицы: поиск, сортировка, страницы; итоги по видимым строкам; добавление и правка записей по правам роли |
| **Админ-панель** | пользователи (создать, изменить роль, сбросить пароль, отключить), журнал действий, служебное |

**Как пользоваться.** При первом входе каждого пользователя открывается короткий тур по интерфейсу (≈ 13 шагов, зависят от роли): подсвечивает листы, фильтры, выводы, вкладки, PDF, данные. Открыть его снова — кнопка «Как пользоваться» в меню слева.

**Оформление.** Дизайн-система VOLT переработана по принципам Apple (навык `apple-design`): светлая тема по умолчанию (тёмная — кнопкой в меню), системный синий акцент, шрифт SF Pro на Mac и Inter на Windows с оптическими размерами, интервал букв по кеглю, полупрозрачные меню и шапка, переключатели как в macOS, пружинная анимация без отскока. Смены на графиках — два оттенка одного синего (день светлее, ночь темнее), палитра проверена на различимость, в том числе при нарушениях цветового зрения.

## Как устроена защита

**Полная версия (сервер).** Пароли — scrypt с индивидуальной солью. Сессия — случайный токен в cookie `HttpOnly; SameSite=Strict`, в базе только его SHA-256; живёт до 12 часов, закрывается после 2 часов без действий. 5 неудачных входов подряд блокируют запись на 15 минут (одинаково и для несуществующих логинов), есть лимит на IP. Права проверяются сервером при каждом запросе: начальник цеха и ОТК получают уже отобранные данные. Защита от CSRF, CSP, журнал действий, нельзя отключить последнего администратора. Страница без входа данных не содержит.

**Запасной HTML (запечатанный файл).** Ключа расшифровки в файле нет:

- у каждого среза данных («всё», «Цех 1», «Цех 2», «только брак») свой случайный ключ AES-256-GCM, срез зашифрован им;
- для каждого пользователя из пароля выводится ключ (PBKDF2-SHA-256, 600 000 итераций, своя соль) — им зашифрована «карточка доступа» с ключом того среза, который положен роли;
- в файле — только соли, служебные числа и шифротекст; логинов, ролей и данных открытым текстом нет (это проверяет тест).

Поэтому начальник цеха своим паролем расшифровывает только свой цех: это ограничение держится на криптографии, а не на скрытых кнопках. Правило «какой роли какие строки» одно и то же для сервера и файла (`scopeRows` в `server/lib/roles.js`).

**Честно о пределах.** Файл можно унести и подбирать пароль без ограничения попыток, поэтому его стойкость равна стойкости паролей (демо-пароли для этого слабые). Сервер по умолчанию слушает только этот компьютер (`127.0.0.1`) по HTTP; для работы по сети его ставят за HTTPS-прокси и включают `PROFIL_SECURE=1`. Сторонний аудит безопасности не проводился — проект учебный.

## Допущения по данным

В журналах нет объёма выпуска и денег, поэтому:
- **«выработка» = доступность оборудования**: фонд времени (станки × дни × смены × длительность смены) минус потери;
- **рубли** — по ставкам из кнопки «Допущения» на Сводке (по умолчанию: смена 8 ч, станко-час простоя 3 000 ₽, бракованная деталь 1 500 ₽). **Это оценка, а не бухгалтерия.**

## Для разработчика

Нужен Node.js 22.18+ (в архиве он есть в `runtime`).

```bash
npm start                 # сервер: http://127.0.0.1:3000
npm run build             # сборка: app → panel/index.html (запечатанный файл) и server/public/index.html
npm test                  # тесты сервера, запечатанного файла и браузерные
npm run verify            # сверка цифр
node tools/seal.js --users мои-пользователи.json   # запечатать файл своими логинами и паролями
```

Переменные сервера: `PORT`, `HOST`, `PROFIL_DB`, `PROFIL_DEMO=0` (без демо-паролей; администратор получит временный пароль в консоли), `PROFIL_ADMIN_PASSWORD`, `PROFIL_SECURE=1`, `PROFIL_TRUST_PROXY=1`. В git-репозитории нет `runtime/node.exe` (90 МБ) — его скачивает и сверяет по контрольной сумме `tools/get-runtime.ps1`.

## Состав репозитория

```
Инструкция.html               инструкция с картинками (собирается tools/make-guide.js)
Запуск сервера Windows.cmd    полная версия для Windows: сервер + база SQLite, откроет браузер
Запуск сервера Mac.command    то же для Mac (Apple Silicon и Intel)
panel/index.html              запечатанная панель (данные зашифрованы); в архиве — «Открыть без сервера.html»
runtime/                      переносной Node.js 24 (node.exe и mac/*.tar.xz) — в git не входят, кладутся в архив
server/                       сервер: index.js, lib/ (база, вход, права, проверка данных), public/ (панель для сервера), seed.json
app/                          исходники панели (React 19, TypeScript, Vite, Tailwind 4, дизайн-система VOLT, графики Bklit UI)
tools/                        сборка запечатанного файла и архива, тесты, сверка
Файлы для проекта/            исходные журналы (CSV и XLSX)
ОПИСАНИЕ.md, КОММЕНТАРИЙ.md   выводы по производству и свободный комментарий (в архив для отправки не входят)
журнал-правок.md              подробный журнал ошибок ИИ и исправлений
```

Архив для отправки собирает `node tools/make-zip.js Профиль_ФИНАЛ.zip --slim`: только запуск, сервер, Node.js, инструкция и исходные журналы.

## Технологии

VOLT — дизайн-система (токены, компоненты, темы), переработанная в стиле Apple; шрифт Inter вшит. Bklit UI — графики. motion и anime.js — движение (при системной настройке «уменьшить движение» перемещения отключаются). SheetJS — чтение XLSX; html-to-image и jsPDF — PDF. Сервер — только встроенные модули Node.js (`node:sqlite`, `node:crypto`, `node:http`), сторонних зависимостей нет. Шифрование в браузере — встроенный WebCrypto.
